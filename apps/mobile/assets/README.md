# App assets

These are **placeholders**, generated by `scripts/generate-placeholder-assets.mjs`
so the project builds end to end before real artwork exists. Replace every file
before submitting to either store.

| File                           | Size      | Requirements                                                                                                         |
| ------------------------------ | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `icon.png`                     | 1024×1024 | No transparency, no rounded corners — iOS applies its own mask.                                                      |
| `adaptive-icon.png`            | 1024×1024 | Android foreground. Keep content inside the centre 66% safe zone; the outer ring gets cropped on round-icon devices. |
| `adaptive-icon-monochrome.png` | 1024×1024 | Android 13+ themed icons. Silhouette only — the system recolours it.                                                 |
| `notification-icon.png`        | 96×96     | Android status bar. Must be **white on transparent**; anything else renders as a white blob.                         |
| `splash.png`                   | 512×512   | Shown on `#FBF8FF`.                                                                                                  |
| `splash-dark.png`              | 512×512   | Shown on `#121318`.                                                                                                  |
| `favicon.png`                  | 48×48     | Web only.                                                                                                            |

Regenerate the placeholders at any time with:

```bash
node scripts/generate-placeholder-assets.mjs
```
